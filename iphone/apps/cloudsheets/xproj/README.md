# CloudSheets

Cloud-hosted spreadsheet clone. Supports opening sheets, cell edit + tap,
switching tabs, searching sheets, and viewing recents.

- Project: `CloudSheets.xcodeproj`
- Scheme / bundle ID: `CloudSheets` / `com.iosworld.benchmark.cloudsheets`
- Tech: Swift + SwiftUI, no storyboard
- Deployment target: iOS 17+

Open `CloudSheets.xcodeproj` in Xcode and run on an iOS Simulator.

MCP: `mcps/cloudsheets.py` — `open_spreadsheet`, `tap_cell`, `edit_cell`,
`switch_tab`, `search_spreadsheets`, `view_recent`.
