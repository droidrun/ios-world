# TeamChat

Team-chat clone (channels + DMs + threads). Supports channel/DM lists,
sending messages, thread replies, and message search.

- Project: `TeamChat.xcodeproj`
- Scheme / bundle ID: `TeamChat` / `com.iosworld.benchmark.teamchat`
- Tech: Swift + SwiftUI, no storyboard
- Deployment target: iOS 17+

Open `TeamChat.xcodeproj` in Xcode and run on an iOS Simulator.

MCP: `mcps/teamchat.py` — `navigate_to_tab`, `list_channels`, `list_dms`,
`open_channel`, `open_dm`, `send_message`, `reply_to_thread`, `search_messages`.
