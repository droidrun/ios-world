# QuickBite

Food-delivery clone. Supports browsing restaurants, menus, adding items to an
order, delivery-address management, and checkout. Used for multi-step ordering
tasks and cross-app flows (payment, notifications).

- Project: `QuickBite.xcodeproj`
- Scheme / bundle ID: `QuickBite` / `com.iosworld.benchmark.quickbite`
- Tech: Swift + SwiftUI, no storyboard
- Deployment target: iOS 17+

Open `QuickBite.xcodeproj` in Xcode and run on an iOS Simulator.

MCP: `mcps/quickbite.py` — `search_restaurants`, `browse_menu`, `add_to_order`,
`checkout`, `contact_support`.
