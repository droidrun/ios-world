# Clock

Clock clone with World Clock, Alarm, Stopwatch, and Timer tabs. Used in the
benchmark for time-aware tasks (alarms, stopwatch reads, cross-timezone logic).

- Project: `Clock.xcodeproj`
- Scheme / bundle ID: `Clock` / `com.iosworld.benchmark.clock`
- Tech: Swift + SwiftUI, no storyboard
- Deployment target: iOS 17+

Open `Clock.xcodeproj` in Xcode and run on an iOS Simulator.

MCP: `mcps/clock.py` — generic `tap`, `swipe`, `type_text`, `observe` primitives.
